# 채권신고 취하서 자동 타이핑 프로그램

## 사용 방법 (온라인 - Vercel)
브라우저에서 배포된 URL에 접속하여 바로 사용합니다.
- 이름 검색 → 동호수/연락처 입력 → 즉시 인쇄

## 로컬 실행 (오프라인)
```
실행하기.bat
```
또는
```
npm start
```

## 개발자용 빌드
```
npm run build
```
> `data/` 폴더에 시부인표 엑셀 파일을 넣은 후 실행하면 데이터가 자동 내장된 `index.html`이 생성됩니다.

## 폴더 구조
```
채권신고취하서/
├── index.html         ← 메인 앱 (자립형, Vercel 배포용)
├── build.js           ← 빌드 스크립트
├── server.js          ← 로컬 서버 (옵션)
├── assets/            ← PDF 양식 파일
├── data/              ← 시부인표 엑셀 (빌드 시 자동 내장)
├── output/            ← 로컬 저장 PDF 및 접수현황 CSV (git 제외)
└── public/            ← 클라이언트 원본 소스
```

## 🛠️ 최근 업데이트 내역 (최종 수정: 2026-05-23)

시스템의 가독성, 사용성, 신뢰성을 향상시키기 위해 다음 개선 작업을 완료하여 배포했습니다.

### 1. UI/UX 개선 및 접수현황 제거
- 메인 화면 내 불필요한 '오늘의 접수 현황' 목록을 완전히 제거하여 전체 레이아웃을 간결하게 최적화했습니다.

### 2. PDF 미리보기 배율 제어 기능 도입
- 크롬/엣지 등의 브라우저 대응을 위해 PDF 미리보기 창 상단에 **➕ 확대 / ➖ 축소 / 🔄 화면맞춤** 줌 제어 버튼을 추가했습니다.

### 3. 인적사항 텍스트 자동 축소(Auto-shrink) 최적화
- 입력된 성명, 동호수, 채권번호, 연락처 글자 수가 너무 길어질 때 표 범위를 벗어나지 않도록 가로 제한 기준을 기존 `300pt`에서 실제 표 너비에 맞춘 `180pt`로 타이트하게 조절하여, 글자 수에 비례해 폰트 크기가 동적으로 작아지도록 튜닝했습니다.

### 4. 필수값 유효성 검사 완화 (자유도 향상)
- 채권 검색 및 지정이 완료되었다면 동호수와 연락처를 공란으로 비워두더라도 경고창(`alert`) 없이 **즉시 인쇄**가 기동되도록 완화했습니다.

### 5. `❓ 사용방법` 가이드 모달 신설
- 좌측 헤더에 도움말 버튼을 추가하고 클릭 시 팝업되는 글래스모피즘 스타일의 상세 사용 가이드 모달을 신설했습니다.

### 6. `📋 목록 확인` 시부인표 데이터 전체 목록 및 초고속 검색 팝업 신설
- 프로그램에 내장(또는 서버에 보관)된 전체 287건의 시부인표 리스트를 한눈에 볼 수 있는 팝업 모달을 추가했습니다.
- 실시간 검색창을 통해 초성/성함/채권번호를 실시간 필터링하여 검색할 수 있습니다.
- 목록에서 특정 행을 클릭하거나 '선택' 버튼을 누르면, **좌측 검색란에 이름이 자동으로 입력되며 3단계 폼 작성을 기동**하도록 자동 연동해 편의성을 최대화했습니다.

### 7. 개인정보 보호 약속 명시
- 사용자 신뢰를 높이기 위해 좌측 최하단 푸터 영역 및 사용방법 모달 하단에 **"입력하신 정보는 제작자나 서버에 저장/기록되지 않으며 무단 도용하지 않는다"**는 개인정보 보호 약속 문구를 고정 표기했습니다.
