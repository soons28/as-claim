# 채권신고 취하서 자동 타이핑 프로그램

## 사용 방법 (온라인 - Vercel)
브라우저에서 배포된 URL에 접속하여 바로 사용합니다.
- 이름 검색 → 동호수/연락처 입력 → 즉시 인쇄

## 로컬 실행 (오프라인)
```
실행하기.bat
```
또는
```
npm start
```

## 개발자용 빌드
```
npm run build
```
> `data/` 폴더에 시부인표 엑셀 파일을 넣은 후 실행하면 데이터가 자동 내장된 `index.html`이 생성됩니다.

## 폴더 구조
```
채권신고취하서/
├── index.html         ← 메인 앱 (자립형, Vercel 배포용)
├── build.js           ← 빌드 스크립트
├── server.js          ← 로컬 서버 (옵션)
├── assets/            ← PDF/Word 양식 파일
├── data/              ← 시부인표 엑셀 (git 제외)
├── output/            ← 로컬 저장 PDF (git 제외)
└── src/               ← 서버 버전 소스
```
