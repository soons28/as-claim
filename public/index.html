💡 채권신고 취하서 작성기 사용 방법

시부인표 데이터를 활용하여 채권신고 취하서를 작성하고 즉시 출력하는 도구입니다.

📌 기본 작성 순서
  1. 채권자 검색 (2단계): 좌측 검색창에 채권자 성함 또는 법인명을 입력한 후 엔터(Enter)나 검색 버튼을 클릭합니다.
  2. 채권 정보 선택 및 수정 (3단계): 검색된 결과에서 원하는 채권번호를 선택합니다. (중복 검색 시 자동 합산 옵션 제공)
  3. 추가 정보 입력: 동호수 및 연락처를 입력합니다. (필요 시 비워두셔도 정상 인쇄됩니다.)
  4. 미리보기 및 즉시 인쇄: 우측 미리보기에서 상태를 확인하고 🖨️ 즉시 인쇄 버튼을 누르면 인쇄 팝업이 바로 기동됩니다.
🔍 미리보기 확대/축소
우측 미리보기 창 상단의 ➖/➕/🔄 버튼을 이용하여 글씨가 너무 작거나 클 때 배율을 손쉽게 변경할 수 있습니다.
🔧 글자 위치 미세조정
프린터의 오차로 출력이 한쪽으로 밀릴 경우, '출력 글자 위치 미세조정' 탭을 열어 가로(X), 세로(Y) 인쇄 위치를 직접 1mm 단위로 미세하게 재설정하여 정확히 인쇄할 수 있습니다.
💾 오프라인 단독 무설치 사용 가능
이 프로그램은 모든 리소스가 내장되어 있어, 인터넷이 끊긴 환경에서도 USB에 담긴 index.html 파일을 더블클릭하기만 하면 오프라인 단독 구동이 가능합니다.
🔒 개인정보 무단 도용 방지 및 보호 서약
본 서비스는 개인정보 무단 사용 및 수집을 엄격히 금지합니다. 입력하시는 인적사항(동/호수, 연락처, 성함 등)은 제작자에게 어떠한 기록도 남지 않으며, 무단 도용하지 않을 것을 보장합니다. 모든 데이터는 출력 즉시 브라우저의 메모리 상에서 소멸하므로 안심하고 사용하셔도 좋습니다.
